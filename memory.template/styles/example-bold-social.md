# Style: bold-social

> A named style the user can ask for by name ("no estilo bold-social"). Copy this file to make a new one.
> Used for: promos, launches, announcements on Instagram / LinkedIn.

## Type
- Headline: Montserrat 900, tracking -20, line height 1.0, 2-3 lines max, one **accent** word in the accent colour
- Kicker above the headline: 28 px, 700, uppercase, tracking 200, on a highlight box
- Body: none or one short line, 32 px+

## Colour
- Dark base (`$ink`), white headline, one loud accent (yellow / lime / the brand's brightest colour)
- Photo on top 60-65% of the canvas, linear shade from transparent to `$ink` under the text

## Layout
- 80 px margins on 1080 wide, everything left-aligned on one edge
- CTA as a pill (radius = height / 2) in `$primary`, bottom-left, with an arrow icon
- Logo small, top-right, in white

## Do
- One message per piece; big type; real photo of the product or person
- Keep text inside the platform safe zone

## Don't
- More than two type weights, centred paragraphs, drop shadows on text, stock-looking handshake photos
